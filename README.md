# 🌐 Kevin Ranpura | Portfolio

A modern, fully responsive portfolio website built with **React**, **Vite**, and **TypeScript** to showcase my projects, technical skills, and experience in **Full Stack Development**, **AI**, and **Agentic AI**.

Designed with smooth animations, interactive visuals, and a clean developer-focused interface.

🔗 **Live Demo:** [Demo](https://kevin-ranpura.vercel.app/)

---

## ✨ Features

- 📱 Fully responsive design for desktop, tablet, and mobile
- 🎨 Interactive particle background using **tsParticles**
- 🌙 Light & Dark theme support
- ⚡ Smooth page transitions and animations with **GSAP** & **Framer Motion**
- ⌛ Skeleton loading screen for improved user experience
- 📂 Dedicated sections for projects, skills, experience, and resume
- 📄 Resume preview and download
- 🚀 Optimized for performance and accessibility

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/kevinranpura/.git
cd your-repository
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```
